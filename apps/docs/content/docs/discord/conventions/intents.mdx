<CodeSpan.Prop identifier="intents" />. were introduced by Discord so that bot developers can choose which events their bot receives based on what data it needs to function. In order for a given event to be emitted, a related intent needs to be enabled.

For example, one of the most used events in Discord bots is <CodeSpan.String magic content="guildMemberAdd"/>, this event is emitted when a member joins the guild, but it is necessary to set the <CodeSpan.String magic content="GuildMembers"/> intent for the event to be emitted.

When generating this project, by default all intents are enabled in the <CodeSpan.Class identifier="Client" />. See below what a simple code would look like without using Constatic Base:

```ts title="src/index.ts"
import { Client } from "discord.js";

const client = new Client({ // [!code word:intents]
    intents: [
        "GuildMembers",
        "MessageContent",
        "Guilds",
        "GuildBans",
        "GuildPresences",
        // ...
    ]
});
```

But it is not necessary to set any intent, because by default, they are all already enabled:

```ts title="src/index.ts"
import { env } from "#env";
import { bootstrap } from "@constatic/base";

await bootstrap({ meta: import.meta, env });
```

However, if you want to set only specific intents, as in the case of a public bot where you do not want to enable the <CodeSpan.String magic content="MessageContent" /> intent, simply use the <CodeSpan.Prop identifier="intents" />. property of the <CodeSpan.Method identifier="bootstrap"/> function, it is the same as the <CodeSpan.Class identifier="Client" /> options:

```ts title="src/index.ts"
import { env } from "#env";
import { bootstrap } from "@constatic/base";

await bootstrap({ // [!code word:intents]
    meta: import.meta, env
    intents: [
        "Guilds",
        "GuildWebhooks",
        "GuildBans",
        // ...
    ]    
});
```
